# CSS 选择器、层叠与优先级

选择器决定规则匹配哪些元素；最终样式还受来源、重要性、层叠层、优先级和顺序影响，不能只数 id 数量。

## 常用匹配

| 选择器                       | 含义                        |
| ---------------------------- | --------------------------- |
| `.card` / `#main` / `button` | 类、id、元素                |
| `.card > p` / `.card p`      | 直接子元素、后代            |
| `h2 + p` / `h2 ~ p`          | 紧邻后续兄弟、后续兄弟      |
| `[type="email"]`             | 属性匹配                    |
| `:hover` / `:focus-visible`  | 状态伪类                    |
| `::before` / `::after`       | 伪元素，不是实际 DOM 子节点 |

`nth-child` 计数所有兄弟元素，`nth-of-type` 按元素类型计数。不要只设计 hover，键盘用户也需要可见焦点。

## 层叠与继承

在可比较的同层规则中按 id、类/属性/伪类、元素/伪元素三个分量比较，不是十进制加法。继承只适用于可继承属性；盒模型尺寸通常不继承。合理组织规则，避免用大量 `!important` 互相覆盖。

### 版本变化与兼容

| 知识点            | 新能力                                                   | 旧环境方案                                             |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| Selectors Level 4 | `:is()` / `:not()` 优先级取参数中最高者，`:where()` 为零 | 拆成基础选择器                                         |
| `:has()`          | 可依据关系元素匹配                                       | 用 @supports selector(:has(*)) 检测并保留基础样式      |
| Cascade Layers    | `@layer` 显式组织层叠                                    | 旧浏览器可能忽略整个层块，基础样式不要只放未支持语法中 |

依据：[Selectors 4](https://www.w3.org/TR/selectors-4/)、[CSS 层叠](https://www.w3.org/TR/css-cascade-5/)。
